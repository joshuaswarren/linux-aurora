## Merge decisions and regressions caught

Use upstream CLC printf ABI and supported-kernel generation, and upstream
returned-atomic placement above the actual spill frame. Retain the preamble
input bitmap, lifetime-aware loader copies, separate preamble resource metadata,
and optional incoming scoreboard dependencies. Preambles remain disabled in
the G17P runtime. No new runtime caller supplies the optional input descriptor.

1. The new short COPY specialization originally hardcoded source discard. Keep
   the existing lifetime decision in that specialization too. Exhaustive checks
   now compare both live and final-read copies with the general composer,
   including extended-form fallback. Existing native-byte and transactional
   rollback tests are preserved.
2. Upstream introduced release drains, but the automatic merge initialized
   the pending-slot mask to zero even with incoming producers. Two new cases
   (unread inputs, and one already consumed incoming slot) failed four checks
   before the fix. Seed pending slots from validated incoming ranges. The
   resulting waits contain only outstanding producers, not blanket barriers.
3. Native integer ballots have live inputs both with and without the source
   cache hint. Carry cache and discard separately instead of discarding either
   native witness. The compiler passes the operand cache annotation for the
   witnessed full-width G17P register-comparison form. Both original witness
   tests now pass.
4. The production minifloat ADD encoder allocated eleven fields for six
   operand/hint fields plus as many as six waits. The existing all-wait-mask
   test reproduced an out-of-bounds write at `agx3_alu_core.c:293` under UBSan,
   and the Linux test aborted with stack smashing. Reserve twelve entries.
   The complete ALU suite now passes with AddressSanitizer and UBSan, and on
   Linux. Accepted encodings and rejected wait combinations are unchanged.

## Multisample and event follow-up

The old dynamic-mask epilog fixture expected no kill updates even though the
lowering deliberately preserved them. Dropping those updates would lose coverage
semantics. Instead, union pure exported-input kill masks and place one update
before all depth/colour outputs. The previous early return for one surviving
depth write left later sample kills after colour stores; that shape is now
handled too. Each mask union is checked against all 256 possible exported masks,
for all 18 nonempty 2x/4x API masks (4,608 semantic comparisons).

The wider regression exposed a separate sparse-store rejection: after zero-mask
colour stores disappear, two or three stores in a four-sample epilog were rejected
by a check that still required four. Admit a nonempty subset, retaining the
sample-count ceiling, one class-12 wait/release, unique reaching mask definitions,
single-partition layout and complete-background requirements. The new packer
regression checks two/three/four stores and rejects missing waits, excessive
sample counts, repeated mask definitions and partial background reloads.
All these tests pass, including the complete `agx_tests` suite and related
MSAA, MRT, zero-mask and early-demote suites. No draw splitting or extra barriers
were introduced. Runtime qualification is still required after the live CTS run.
The coverage-hoisting helper currently has a Vulkan caller only. The shared
packer change also needs Gallium execution coverage; the desktop GL diagnostic
and software control are documented in `GL33-SPARSE-DEPTH-QUALIFICATION.md`.

Offline Apple captures in `native-sparse-sample-depth-20260916` compare full mask,
mask 5 and odd-sample discard shaders. They compile successfully and retain the
same transaction structure, but this compiler emits a single sample-rate body;
these are not a new exact two-store/four-sample witness or hardware execution.
The sparse admission follows zero-store elimination and the existing per-store
mask contract, not an invented native encoding.

The event poll explicitly requests coherent memory. Its old golden encoded the
pre-coherence LDDEV byte; the new expected f77 bit matches the existing native
atomic-load vector. This is a fixture correction, not a production memory-ordering
change. `agx3_event_wait` now passes. The remaining 18 test names also fail on
the pinned upstream build; only the precompiled fixture and sequential-dispatch
ASLR diagnostics differ after normalization. See the refreshed comparison JSON.
